SIMONIKA 3.0

Proyek sistem informasi manajemen yang dikembangkan untuk Bappenas. Saya berkontribusi dalam pengembangan backend dan koordinasi proyek.

PHP CodeIgniter MySQL GitLab Jira

Deskripsi lengkap

Latar belakang

Proyek SIMONIKA dikembangkan selama masa kerja praktik di Kementerian Perencanaan Pembangunan Nasional (Kementerian PPN/BAPPENAS). Sistem ini diinisiasi untuk menjawab kebutuhan instansi akan platform digital yang mampu mengelola, memonitor, dan memproses data secara lebih efisien dan terintegrasi.

Tujuan

Membangun infrastruktur backend yang tangguh dan aman untuk aplikasi SIMONIKA, sekaligus mengawal kelancaran siklus pengembangan agar sesuai dengan jadwal dan spesifikasi kebutuhan dari pihak kementerian.

Fitur utama

  • Pengembangan dan pengelolaan modul-modul backend untuk pemrosesan data instansi.
  • Manajemen basis data (database) yang terstruktur untuk mendukung skalabilitas aplikasi.
  • Penyediaan integrasi API yang optimal untuk fungsionalitas antarmuka.

Proses pengerjaan

Proyek ini menuntut peran ganda sebagai Backend Developer sekaligus Project Manager. Alur pengerjaan dimulai dari tahap analisis kebutuhan sistem bersama tim BAPPENAS, perancangan arsitektur data, pengkodean sistem backend, hingga fase pengujian dan dokumentasi teknis.

Tantangan

Membagi fokus antara manajemen proyek secara makro (memastikan target waktu tercapai) dengan beban kerja teknis yang sangat mendetail pada penulisan kode backend.

Solusi

Menerapkan pembagian tugas dan lini masa (timeline) yang sangat terstruktur, serta membangun arsitektur backend yang modular sehingga proses pengembangan fitur dan debugging dapat dilakukan dengan lebih cepat tanpa mengganggu modul lain.

Peran dan kontribusi

Mengembangkan backend dan membantu koordinasi pengerjaan proyek SIMONIKA 3.0 di Bappenas.
