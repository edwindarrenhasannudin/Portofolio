SIMONIKA 3.0

A management information system developed for Bappenas. I contributed to backend development and project coordination.

PHP CodeIgniter MySQL GitLab Jira

Project overview

Background

SIMONIKA was developed during my internship at the Ministry of National Development Planning of the Republic of Indonesia (Bappenas). The project was initiated to address the ministry's need for a digital platform to manage, monitor, and process data more efficiently through an integrated system.

Objectives

Build a reliable and secure backend for SIMONIKA while coordinating the development lifecycle to meet the ministry's requirements and schedule.

Key contributions

  • Developed and maintained backend modules for processing organizational data.
  • Structured database management to support application scalability.
  • Supported API integration with the application interface.

Development process

I took on both backend development and project coordination responsibilities. The work included analyzing requirements with the Bappenas team, designing the data architecture, implementing the backend, and supporting testing and technical documentation.

Challenge

Balancing project coordination and delivery schedules with the detailed technical work required to develop the backend.

Solution

I used a structured task breakdown and timeline, and built a modular backend architecture. This helped the team develop features and debug issues more efficiently without disrupting other modules.

Role and responsibilities

I contributed to backend development and coordinated work on the SIMONIKA 3.0 project at Bappenas.
