Pharmacy Information System

A web-based pharmacy management and inventory system. This project focuses on organizing pharmacy information and stock workflows in one application.

PHP MySQL Bootstrap CRUD Information System

Project overview

Background

Pharmacy operations rely on accurate, accessible information about products and inventory. This project was created as a web-based information system for pharmacy management.

Objective

Provide a central application for managing pharmacy information and inventory, with data operations handled through CRUD functionality.

Technology

PHP handles the application logic, MySQL stores system data, and Bootstrap supports the user interface.
