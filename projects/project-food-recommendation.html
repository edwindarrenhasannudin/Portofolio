Food Ingredient Recommendation System

A recommendation system that explores food ingredient substitution using Content-Based Filtering. This project was developed as a bachelor's thesis.

Python Content-Based Filtering Pandas Data Analysis

Project overview

Background

Finding an alternative ingredient can help when a recipe's original ingredient is unavailable or needs to be replaced. This thesis focuses on food ingredient substitution as a recommendation problem.

Objective

Develop a system that recommends substitute food ingredients using similarities between ingredient content, applying a Content-Based Filtering approach.

Approach

The project applies Content-Based Filtering to the ingredient recommendation task. Python and Pandas are listed among the tools used for implementation and data analysis.

Project scope

The current project summary covers the recommendation method and ingredient-substitution use case. Dataset details, similarity attributes, evaluation results, and other thesis findings can be documented here as the full project description is added.
