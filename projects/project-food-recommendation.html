Bachelor's thesis

Food Ingredient Recommendation System

A food ingredient substitution recommendation system developed as a bachelor's thesis. It combines a React web application with Python-based nutrition data preprocessing and Content-Based Filtering.

TypeScript React 18 Vite 6 Tailwind CSS 4 Python Content-Based Filtering

Project overview

Background

Finding an alternative ingredient can help when a recipe's original ingredient is unavailable or needs to be replaced. This thesis focuses on food ingredient substitution as a recommendation problem.

Objective

Develop a system that recommends substitute food ingredients using similarities between ingredient content, applying a Content-Based Filtering approach.

Technical architecture

The web application is built with TypeScript and React 18, using Vite 6 for development and builds and Tailwind CSS 4 for styling. The Content-Based Filtering recommendation calculation is also implemented in TypeScript. No Django, Flask, or FastAPI backend is indicated in the project structure.

Data processing and dependencies

Python scripts handle nutrition data preprocessing and analysis, including one-hot encoding and scaling. They use pandas, scikit-learn, NumPy, Matplotlib, and openpyxl. The thesis repository's current requirements.txt lists only NumPy and Matplotlib, so the other imported packages should also be documented as dependencies.

Tools and methods

The project combines a React 18 and TypeScript web application (built with Vite 6 and styled with Tailwind CSS 4) with Python data-processing scripts. Nutrition preprocessing uses one-hot encoding and scaling, while ingredient alternatives are recommended with Content-Based Filtering. Python analysis uses pandas, scikit-learn, NumPy, Matplotlib, and openpyxl.
