🚀 HOW TO USE

Edit CSS:
  Ubah warna?      → styles/variables.css
  Ubah home?       → styles/home.css
  Ubah mobile?     → styles/responsive.css
  Ubah animasi?    → styles/animations.css

Edit JavaScript:
  Ubah menu?       → js/navbar.js
  Ubah scroll?     → js/scroll-navigation.js
  Ubah carousel?   → js/certificates.js atau js/projects.js
  Ubah splash?     → js/splash-screen.js

Add Certificate:
  1. Tambah image ke assets/
  2. Update array di js/certificates.js
  3. Update dots di index.html (jika perlu)
